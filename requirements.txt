# ---------------------------------------------------------------------------
# Fortum AI-Powered Procurement Analysis - Python dependencies
#
#   python3 -m venv myenv
#   source myenv/bin/activate
#   pip install --upgrade pip
#   pip install -r requirements.txt
#
# Requires Python 3.9 or newer.
#
# The agents are built so that the classical NLP stack does the bulk of the
# work and a large language model is consulted only for the residue that the
# deterministic layers cannot resolve. Every neural component listed here runs
# locally on CPU, which is what keeps the per-row cost at zero.
# ---------------------------------------------------------------------------

# --- Data access -----------------------------------------------------------
# Tabular handling and the Excel reader. openpyxl is used in read-only,
# streaming mode so that million-row workbooks do not have to fit in memory.
pandas>=2.0
numpy>=1.24
openpyxl>=3.1

# --- Classical NLP ---------------------------------------------------------
# NLTK supplies the Snowball stemmers (which cover Finnish, Swedish, Norwegian,
# Danish, German and Dutch), the stop-word lists and the collocation finder
# used to detect recurring multi-word procurement terms.
nltk>=3.8

# spaCy supplies tokenisation, lemmatisation, part-of-speech tagging and named
# entity recognition.
#
# The language pipelines it needs are NOT listed here. They are published on
# GitHub rather than PyPI, and a single unreachable host in this file fails the
# whole install - which is what happens on a corporate network that inspects
# TLS, for components every agent treats as optional. They live in
# requirements-models.txt instead:
#
#   pip install -r requirements.txt
#   pip install -r requirements-models.txt      # optional, improves accuracy
spacy>=3.8.0,<3.9

# Vectorisation, nearest-neighbour search and agglomerative clustering.
scikit-learn>=1.3
scipy>=1.10

# C++ implementation of the edit-distance family. Roughly two orders of
# magnitude faster than difflib, which matters when blocking a million lines.
rapidfuzz>=3.6

# --- Neural components (local, CPU, no per-call cost) ----------------------
# Multilingual sentence embeddings. This is the component that makes semantic
# grouping, catalogue matching and supplier-portfolio comparison possible
# without sending anything to a language model.
sentence-transformers>=2.6

# Hosts the Helsinki-NLP opus-mt translation models. Offline machine
# translation removes the single largest language-model cost driver, so losing
# it is expensive rather than merely slower: every foreign phrase then falls
# through to the paid tier. The agents load Marian directly instead of through
# pipeline("translation"), which version 5 removed, so either major version
# works. The ceiling is only there to stop the next major release enabling
# itself unread.
transformers>=4.40,<6
torch>=2.1
sentencepiece>=0.2
sacremoses>=0.1

# --- Utilities -------------------------------------------------------------
# HTTP client for the language-model backends. The agents fall back to
# urllib from the standard library when this is absent.
requests>=2.31

# Verifies TLS against the operating system's certificate store instead of
# certifi's bundle. On a corporate network that re-signs HTTPS, the proxy's root
# is installed in the system store - which is why the browser works - and is
# absent from certifi's, which is why Python reports "self-signed certificate in
# certificate chain" when fetching models. This removes that whole class of
# problem without exporting certificates by hand. Optional: where it is not
# installed, verification is unchanged.
truststore>=0.9; python_version >= "3.10"

# Statistical language identification, used only to break ties that the
# built-in marker heuristic leaves unresolved.
langdetect>=1.0.9

# Progress reporting for the long passes over large inputs.
tqdm>=4.66

# ---------------------------------------------------------------------------
# The test harness - nothing to install
# ---------------------------------------------------------------------------
#
#   python app.py
#
# TestAgent.py and app.py deliberately depend on nothing beyond the standard
# library, and React is vendored under static/js/vendor rather than fetched or
# built. A harness that needs its own set-up is a harness people stop running,
# so it works on a machine where none of the above has been installed yet.
#
# ---------------------------------------------------------------------------
# Language resources - install after the packages above
# ---------------------------------------------------------------------------
#
#   pip install -r requirements-models.txt        # the spaCy pipelines
#
#   python -m nltk.downloader punkt punkt_tab stopwords wordnet omw-1.4
#
# The translation and embedding models are fetched from the Hugging Face hub on
# first use and cached under ~/.cache/huggingface. A machine that cannot reach
# huggingface.co does not fail; it silently sends every foreign phrase to the
# language model instead, which is slow and not free. Pre-load them:
#
#   python fetch_models.py
#
# On a machine with no route to the hub at all, run that script somewhere that
# has one and copy the cache across. See "Preparing a machine that cannot reach
# Hugging Face" in README.md.
